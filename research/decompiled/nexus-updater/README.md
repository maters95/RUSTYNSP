# Nexus Updater Decompilation

This is a fresh ILSpy 11.2 decompilation of the supplied
`NexusUpdater.exe`, using its adjacent PDB for symbol/variable names. It is
analysis output, not vendor source. The updater was not modified or rebuilt;
its generated project targets .NET Framework 4.8 and has not been validated as
a recompilable project in this Linux environment.
